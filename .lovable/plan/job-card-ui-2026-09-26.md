Reference image jaisa clean, mobile-first job listing card banana, bina reference screenshot ko page mein embed kiye.

## Build
- White rounded job card with subtle layered shadow/background shape.
- Profile photo placeholder, name, posted time, and heart action in the header.
- Job title, muted description, and compact skill tags.
- Prominent hourly price range with remote-work details.
- Full-width blue Apply button with lightning icon and working pressed/feedback state.
- Desktop par card centered rahega; mobile par proportions reference ke qareeb rahengi.

## Visual system
- Neutral white/gray surfaces with a bright blue primary action.
- Compact sans-serif typography, restrained radius, subtle shadows, and accessible contrast.
- All colors and reusable visual values will use semantic design tokens.
